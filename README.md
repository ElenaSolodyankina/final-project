Планировщик задач (Task Scheduler)

Веб сервер для управления задачами с поддержкой повторяющихся событий.

Проект представляет собой backend для планировщика задач с функционалом:
	- CRUD для задач: создание, чтение, обновление, удаление;
	- Повторяющиеся задачи: поддержка правил "d <N>" (повторение задач каждые N дней) и "y" (ежегодно);
	- Валидация дат: автоматическая коррекция дат в прошлом.

Сервер запустится на порту 7540
Доступ в браузере http://localhost:7540
